# report-quality

## Instructions

1. Review each finding for three links: metric math, lineage path, and driver evidence rows.
2. Flag unsupported or over-specific claims.
3. Flag driver rows that are unrelated to the metric being explained.
4. Prefer a short correction over a long rewrite.
5. Treat missing evidence as a limitation, not as permission to invent an explanation.
6. Confirm the final report can be read by a finance stakeholder without seeing the Python code.
